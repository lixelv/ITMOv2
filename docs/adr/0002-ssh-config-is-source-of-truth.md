# `~/.ssh/config` — единственное хранилище Server

massh читает Server List из `~/.ssh/config` и записывает изменения (добавление/правка Server) туда же, без собственной базы серверов. Так обычный `ssh` в терминале и massh всегда видят одно и то же; цена — massh обязан править чужой, написанный руками файл, не ломая его.
