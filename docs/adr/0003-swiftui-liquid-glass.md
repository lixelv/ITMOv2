# Нативное приложение на SwiftUI с Liquid Glass в духе Xcode

massh пишется на Swift + SwiftUI, использует Liquid Glass как дизайн-систему и по стилю должен выглядеть как родное приложение Apple — ориентир Xcode (сайдбар, рабочая область, инспектор, стандартные контролы без кастомной «темы»). Это привязывает приложение к macOS 26+ и исключает кроссплатформенность (Tauri/Electron отвергнуты): клиент нужен только для macOS, и важнее нативный вид.
