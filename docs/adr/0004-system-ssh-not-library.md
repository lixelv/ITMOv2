# Терминал и SSH-соединения идут через системный `/usr/bin/ssh`

Терминал — SwiftTerm, внутри которого запущен системный `ssh <server>`; служебные соединения (установка Agent, доступ к нему) тоже идут через системный `ssh` с ControlMaster. Так ProxyJump, ssh-agent, ключи и known_hosts работают ровно как в обычном терминале без повторной реализации `~/.ssh/config`. Отвергнута встроенная SSH-библиотека (Citadel/SwiftNIO SSH): больше контроля, но дублирование поведения OpenSSH и его багов.
