# Agent слушает только localhost, приложение ходит к нему через SSH-туннель

Agent слушает `127.0.0.1:12092`, а не внешний интерфейс; приложение пробрасывает порт через `ssh -L` поверх ControlMaster-соединения. Шифрование и аутентификацию даёт SSH, поэтому у Agent нет своего TLS, токенов и правил файрвола, и он не торчит в интернет. Цена — для просмотра сведений нужно SSH-соединение, хотя бы фоновое. Online/Offline от Agent не зависит: это TCP-проверка SSH-порта.

## Considered Options

- Открытый порт 12092 с открытием в файрволе, TLS и токеном доступа. Отвергнуто: лишняя поверхность атаки и собственная криптография ради доступа без SSH.
