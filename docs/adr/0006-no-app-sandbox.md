# Приложение работает без App Sandbox и не распространяется через Mac App Store

App Sandbox запрещает запускать `/usr/bin/ssh` и читать/писать `~/.ssh/config`, на чём построены ADR 0002 и ADR 0004. Поэтому massh собирается без песочницы и распространяется вне Mac App Store; в первой версии — локальная сборка без нотаризации.
