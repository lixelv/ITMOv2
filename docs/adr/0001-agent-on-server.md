# Сведения о сервере отдаёт постоянно работающий Agent-демон на Go

Порты, процессы, контейнеры и ресурсы massh получает от собственного Agent — демона на Go, запущенного на Server и передающего данные в реальном времени через WebSocket на `127.0.0.1:12092` (доступ — только через SSH-туннель, см. ADR 0005). Agent ставится как systemd-сервис `massh-agent.service` от пользователя `massh` (группа `docker`, capabilities `CAP_SYS_PTRACE` и `CAP_DAC_READ_SEARCH`), без полного root. Демон выбран вместо разового запуска по SSH ради живого потока данных; цена — Agent нужно устанавливать, обновлять и держать запущенным на каждом Server. Обязательное ограничение: в простое (нет подключённых клиентов) Agent не собирает данные и потребляет ≈0 CPU. Истории метрик Agent не хранит: графики строит приложение только за время подключения.

## Considered Options

- Без агента: команды `ss`/`systemctl`/`docker` по SSH и парсинг вывода. Отвергнуто ради точности и единого формата.
- Agent по запросу (`massh-agent watch` через SSH exec, без демона). Отвергнуто: пользователь предпочёл постоянное сокет-соединение для живых данных.
