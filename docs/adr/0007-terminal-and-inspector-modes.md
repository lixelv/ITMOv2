# Окно в два режима, Terminal и Inspector, вместо третьей колонки

Справа от Server List одна область на всю ширину с двумя режимами: Terminal (терминальные вкладки) и Inspector (состояние выбранного Server). Режим переключается сегментированным переключателем в тулбаре и сочетаниями ⌘1/⌘2. Он один на окно, а действия, которые открывают вкладку (Connect, двойной клик, установка или удаление Agent), сами переводят окно в Terminal. Inspector на всю ширину вмещает одну прокручиваемую страницу с Overview, Containers, Processes и Ports, а не узкую колонку с вкладками. Цена такая: терминал и состояние Server больше не видны одновременно.

## Considered Options

- Три колонки, как в Xcode: Server List, терминал, инспектор справа. Отвергнуто: узкой колонке не хватает места на наглядное представление Process, Container и портов, а две боковые панели конфликтуют при раскрытии (правая сжимает контент, левая схлопывается скачком).
- Три колонки с переключением режима только у инспектора. Отвергнуто: ширина остаётся той же проблемой.
