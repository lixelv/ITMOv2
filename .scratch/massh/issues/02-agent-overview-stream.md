# 02: Agent: живой поток «Обзора»

**What to build:** Agent запускается на Linux, слушает WebSocket на `127.0.0.1:12092` и, пока подключён хотя бы один клиент, раз в секунду отдаёт Snapshot с обзором: ОС, ядро, uptime, load average, CPU (модель, ядра, загрузка общая и по ядрам), RAM и swap, диски по точкам монтирования, скорость сети. Без клиентов ничего не собирает. Порты, Process и Container пока пустые.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Слушает только `127.0.0.1:12092`, внешний интерфейс недоступен
- [ ] Клиент получает валидный по контракту Snapshot раз в секунду
- [ ] CPU % и скорость сети считаются между соседними снимками
- [ ] Без подключённых клиентов сбор не идёт и CPU ≈ 0 (проверено в тесте)
- [ ] Несколько клиентов одновременно получают поток
- [ ] Go-тесты сбора на фикстурах `/proc`
- [ ] Интеграционный тест: Agent в Linux-контейнере OrbStack, тест подключается по WebSocket и проверяет Snapshot
- [ ] Собирается статически под linux/amd64 и linux/arm64
