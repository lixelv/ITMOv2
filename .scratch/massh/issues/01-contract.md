# 01: Контракт: Snapshot и публичное API MasshCore

**What to build:** Зафиксировать точку стыковки всех частей massh. Описан формат Snapshot (версия формата, версия Agent, время, обзор, порты, Process, Container или признак «Docker не установлен») — одинаково на стороне Agent (Go) и MasshCore (Swift). Набор общих эталонных JSON-Snapshot лежит в одном месте и используется тестами обеих сторон. Описаны протоколы публичного API MasshCore — хранилище Server, монитор доступности, сессия наблюдения, операции с Agent — и их фейковые реализации, на которых MasshApp сможет работать без сервера.

**Blocked by:** None (can start immediately)

**Status:** done

- [x] Swift-модели MasshCore декодируют все эталонные JSON: обычный, без Docker, с пустыми списками, с прошлой версией формата (тест)
- [x] Неизвестная более новая версия формата распознаётся и не приводит к падению
- [x] Протоколы хранилища Server, монитора доступности, сессии наблюдения и операций с Agent описаны в MasshCore
