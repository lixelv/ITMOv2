# 22: Режимы окна Terminal и Inspector

**What to build:** Убрать колонку инспектора. Справа от Server List одна область на всю ширину с режимами Terminal и Inspector (ADR 0007, GLOSSARY «Окно»). Переключатель `Terminal | Inspector` в тулбаре заменяет кнопку «Inspector», сочетания ⌘1/⌘2. Режим один на окно. Connect, двойной клик по Server, установка и удаление Agent переключают в Terminal. Одиночный выбор Server режим не меняет. Предложение установить Agent и плашки состояния Agent показываются вверху Inspector.
