# 09: Установка, обновление и удаление Agent

**What to build:** MasshCore умеет установить, обновить и удалить Agent на Server: определяет архитектуру, загружает подходящий бинарник из приложения и готовит команду установщика, которая выполняется в терминальной вкладке (sudo-пароль вводит пользователь). Установщик создаёт пользователя `massh` (группа `docker`), systemd-юнит `massh-agent.service` с capabilities `CAP_SYS_PTRACE` и `CAP_DAC_READ_SEARCH` и включает автозапуск.

**Blocked by:** 02, 08

**Status:** done

- [x] Установка на чистый Linux-контейнер с systemd приводит к работающему Agent, который отдаёт Snapshot через сессию наблюдения
- [x] Agent переживает перезапуск сервиса и машины (юнит enabled)
- [x] Agent не работает от root
- [x] Обновление заменяет бинарник и перезапускает сервис, версия в Snapshot меняется
- [x] Удаление останавливает сервис, удаляет юнит, бинарник и пользователя
- [x] Приложение никогда не получает sudo-пароль
- [x] Повторная установка идемпотентна
