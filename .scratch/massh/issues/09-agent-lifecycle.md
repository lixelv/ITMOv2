# 09: Установка, обновление и удаление Agent

**What to build:** MasshCore умеет установить, обновить и удалить Agent на Server: определяет архитектуру, загружает подходящий бинарник из приложения и готовит команду установщика, которая выполняется в терминальной вкладке (sudo-пароль вводит пользователь). Установщик создаёт пользователя `massh` (группа `docker`), systemd-юнит `massh-agent.service` с capabilities `CAP_SYS_PTRACE` и `CAP_DAC_READ_SEARCH` и включает автозапуск.

**Blocked by:** 02, 08

**Status:** ready-for-agent

- [ ] Установка на чистый Linux-контейнер с systemd приводит к работающему Agent, который отдаёт Snapshot через сессию наблюдения
- [ ] Agent переживает перезапуск сервиса и машины (юнит enabled)
- [ ] Agent не работает от root
- [ ] Обновление заменяет бинарник и перезапускает сервис, версия в Snapshot меняется
- [ ] Удаление останавливает сервис, удаляет юнит, бинарник и пользователя
- [ ] Приложение никогда не получает sudo-пароль
- [ ] Повторная установка идемпотентна
