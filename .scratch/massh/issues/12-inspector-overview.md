# 12: MasshApp: инспектор «Обзор» и графики

**What to build:** Клик по Server открывает инспектор с вкладкой «Обзор»: ОС, ядро, uptime, load average, CPU (общая и по ядрам), RAM и swap, диски, сеть — с обновлением раз в секунду. Графики CPU, RAM и сети за время текущего подключения. На фейковом потоке Snapshot.

**Blocked by:** 10

**Status:** done
