# 11: MasshApp: терминальные вкладки

**What to build:** Двойной клик по Server или кнопка в тулбаре открывает вкладку терминала с системным `ssh <server>` в SwiftTerm. Можно держать несколько вкладок к одному и к разным Server; при переключении вкладки инспектор показывает её Server; завершённая сессия видна.

**Blocked by:** 10

**Status:** done

- [x] Во вкладке работает настоящий `ssh` со всеми настройками `~/.ssh/config`, ключами и ssh-agent
- [x] Несколько вкладок к одному Server и к разным Server одновременно
- [x] Выбор вкладки выбирает её Server в сайдбаре и инспекторе
- [x] Завершение `ssh` показывает состояние «сессия завершена»
- [x] Можно запустить во вкладке произвольную команду (нужно для установки Agent)
