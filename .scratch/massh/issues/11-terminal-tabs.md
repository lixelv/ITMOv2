# 11: MasshApp: терминальные вкладки

**What to build:** Двойной клик по Server или кнопка в тулбаре открывает вкладку терминала с системным `ssh <server>` в SwiftTerm. Можно держать несколько вкладок к одному и к разным Server; при переключении вкладки инспектор показывает её Server; завершённая сессия видна.

**Blocked by:** 10

**Status:** ready-for-agent

- [ ] Во вкладке работает настоящий `ssh` со всеми настройками `~/.ssh/config`, ключами и ssh-agent
- [ ] Несколько вкладок к одному Server и к разным Server одновременно
- [ ] Выбор вкладки выбирает её Server в сайдбаре и инспекторе
- [ ] Завершение `ssh` показывает состояние «сессия завершена»
- [ ] Можно запустить во вкладке произвольную команду (нужно для установки Agent)
