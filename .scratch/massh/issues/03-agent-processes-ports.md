# 03: Agent: Process и порты

**What to build:** В Snapshot появляются все пользовательские Process (PID, имя, пользователь, CPU %, RAM, команда) без потоков ядра и все слушающие порты (протокол, адрес, порт) с владельцем-Process (PID и имя).

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] Потоки ядра в список Process не попадают, системные процессы попадают
- [ ] CPU % процесса считается между снимками
- [ ] Каждый слушающий TCP/UDP-сокет присутствует с протоколом, адресом и портом
- [ ] Для порта указан владелец-Process, если хватает прав; иначе владелец пуст, а порт всё равно показан
- [ ] Go-тесты на фикстурах `/proc`, интеграционный тест в контейнере с запущенным тестовым сервисом на известном порту
