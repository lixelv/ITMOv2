# 08: MasshCore: сессия наблюдения

**What to build:** Для выбранного Server MasshCore поднимает ControlMaster-соединение через системный `ssh`, пробрасывает туннель к `127.0.0.1:12092`, подключается по WebSocket и отдаёт поток Snapshot и состояний: подключение, нет Agent, Agent устарел, соединение потеряно, переподключение.

**Blocked by:** 01, 02

**Status:** done

- [x] Поток Snapshot приходит раз в секунду с реального Agent в контейнере OrbStack
- [x] Нет Agent на Server → состояние «нет Agent»
- [x] Версия Agent старше версии в приложении → состояние «Agent устарел» (данные при этом идут)
- [x] Обрыв соединения → «соединение потеряно», затем автоматическое переподключение
- [x] Закрытие сессии закрывает туннель и не оставляет висящих процессов `ssh`
- [x] Тесты на фейковом WebSocket-сервере плюс интеграционный тест с контейнером
