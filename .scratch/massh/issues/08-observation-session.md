# 08: MasshCore: сессия наблюдения

**What to build:** Для выбранного Server MasshCore поднимает ControlMaster-соединение через системный `ssh`, пробрасывает туннель к `127.0.0.1:12092`, подключается по WebSocket и отдаёт поток Snapshot и состояний: подключение, нет Agent, Agent устарел, соединение потеряно, переподключение.

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [ ] Поток Snapshot приходит раз в секунду с реального Agent в контейнере OrbStack
- [ ] Нет Agent на Server → состояние «нет Agent»
- [ ] Версия Agent старше версии в приложении → состояние «Agent устарел» (данные при этом идут)
- [ ] Обрыв соединения → «соединение потеряно», затем автоматическое переподключение
- [ ] Закрытие сессии закрывает туннель и не оставляет висящих процессов `ssh`
- [ ] Тесты на фейковом WebSocket-сервере плюс интеграционный тест с контейнером
